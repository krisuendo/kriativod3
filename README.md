## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/yourusername/kriativod3.git
cd kriativod3
```

### Run Locally

```bash
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```

---

## 🔑 Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key_here
```
